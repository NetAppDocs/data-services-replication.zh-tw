= 登入NetApp Replication
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用NetApp Console登入NetApp Replication。

若要登入 Console，您可以使用 NetApp 支援網站憑證，也可以使用您的電子郵件和密碼註冊 NetApp 雲端登入 https://docs.netapp.com/us-en/console-setup-admin/task-logging-in.html["了解有關登入的更多信息"^]。

.步驟
. 開啟 Web 瀏覽器並前往 https://console.netapp.com/["NetApp Console"^]。
. 登入控制台。
. 從控制台左側導覽中，選擇*保護*>*複製*。
