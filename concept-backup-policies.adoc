= 了解NetApp Replication中所使用的備份策略

:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
與鏡像策略不同，備份（SnapVault）策略使用NetApp Replication將特定快照副本複製到目標磁碟區。如果您想使用自己的策略而不是預設策略，那麼了解備份策略的工作原理非常重要。



[[understanding-the-relationship-between-snapshot-copy-labels-and-backup-policies]]
== 了解快照複製標籤和備份策略之間的關係

快照策略定義系統如何建立磁碟區的快照副本。此策略指定何時建立快照副本、保留多少個副本以及如何標記它們。例如，系統可能每天凌晨 12:10 建立一個快照副本，保留最近的兩個副本，並將其標記為「每日」。

備份原則包含一些規則，用於指定要將哪些標籤的快照副本複寫到目的地 Volume 以及要保留多少個副本。備份原則中定義的標籤必須與快照原則中定義的一個或多個標籤相符。否則，系統將無法複寫任何快照副本。

例如，如果備份原則包含「每日」和「每週」標籤，則只會複寫包含這些標籤的快照副本。其他快照副本不會被複寫，如下"映像"所示：

image:diagram_replication_snapvault_policy.png["圖示顯示快照原則、來源 Volume、根據快照原則建立的快照副本，然後根據備份原則將這些快照副本複寫到目的地 Volume，該備份原則指定複寫帶有「每日」和「每週」標籤的快照副本。"]



[[default-policies-and-custom-policies]]
== 預設策略和自訂策略

預設快照策略會建立每小時、每天和每週的快照副本，並保留 6 個每小時、2 個每天和 2 個每週的快照副本。

您可以輕鬆地將預設備份原則與預設快照原則結合使用。預設備份原則複寫每日和每週的快照副本；它會保留 7 個每日快照副本和 52 個每週快照副本。

如果您建立自訂策略，則這些策略定義的標籤必須相符。您可以使用系統管理員建立自訂策略。
